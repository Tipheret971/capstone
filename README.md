# [오르페우스의 선율]
---
## 프로젝트 개요
- **장르**: 리듬 플랫포머
- **플랫폼**: PC (Windows)
- **개발 환경**: Unity (6000.0.43f1), Unity Version Control, C#
- **개발 기간**: 2025.03 ~ 2025.12
---
## 핵심 기능 및 특징

### 1. [물리 기반 인터렉션 기믹]
- 점프, 중력반전, 무빙 플랫폼
- 낙하 가속을 통한 조작감 확보

### 2. [오르페우스 신화 기반 스토리라인]
- 오르페우스 신화 스토리 라인과 그에 맞춘 기믹 배치

### 3. [물리 기믹의 BPM 연동]
- 배경음악의 BPM에 맞춘 기믹 동작으로 생동감 전달
---
## 프로젝트 구조
```text
Assets/
├── Scripts/            # 대부분의 스크립트
│   ├── CountDoor/      # 음악기호 습득 개수 카운트 및 문 열림 제어 스크립
│   ├── Settigs Script/ # UI 제어 스크립트
├── ImageFile/          # 외부 이미지
├── 그래픽/              # 자체 제작 도트이미지
├── Animation/          # 캐릭터 이동 스프라이트와 제어 스크립트
└── Sound/              # 사운드 에셋
